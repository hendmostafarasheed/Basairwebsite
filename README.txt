أكاديمية بصائر للقرآن والعلوم الشرعية
=================================
طريقة النشر على GitHub Pages:
1. أنشئ مستودعًا عامًا جديدًا على GitHub.
2. ارفع ملفات ZIP الثلاثة (index.html والصورتان) بعد فك الضغط إلى جذر المستودع مباشرة، دون مجلدات.
3. من Settings > Pages اختر Deploy from a branch ثم main و /(root) واحفظ.
4. انتظر ظهور رابط الموقع.

الأزرار الجاهزة:
- جميع روابط التنقل بين الأقسام تعمل.
- التسجيل يفتح استمارة ثم رسالة واتساب جاهزة على رقم الأكاديمية 01207244946.
- زر التواصل عبر واتساب يعمل.
- أزرار الحلقات والاختبارات والتسميع تعرض رسالة واضحة لحين إضافة الروابط الحقيقية.

لإضافة روابط الحلقات الثابتة:
افتح index.html وابحث عن const CONFIG في آخر الملف.
املأ القيم الفارغة داخل live برابط اجتماع Google Meet أو Zoom (https://...).
quran = حلقة تحفيظ القرآن
 tajweed = التجويد
 sharia = العلوم الشرعية

داخل resources:
tests = رابط الاختبارات
audio = رابط رفع التسجيلات (يجب أن يكون نموذجًا آمنًا خاصًا بالأكاديمية)
reports = رابط بوابة التقارير (يجب أن تكون محمية بصلاحيات تسجيل دخول)

تنبيه أمني: الموقع ثابت ولا يحفظ بيانات الطلاب؛ لا تضف روابط تقارير الطلاب الخاصة أو ملفاتهم العامة إلى الموقع.
الخطوط تُحمّل من Google Fonts عند الاتصال بالإنترنت، وتوجد خطوط احتياطية عند عدم توفرها.
